# Mumbai Civil Builders - Corporate Website

Welcome to the official repository for the **Mumbai Civil Builders** website. This project is a professional digital presence designed for a construction and infrastructure firm operating in the Mumbai Metropolitan Region.

## 🏗️ About the Project
This website serves as a comprehensive portfolio for civil engineering, residential redevelopment, and commercial construction projects. It is built to handle the specific needs of the Mumbai real estate market, focusing on trust, structural integrity, and urban planning.

## 🚀 Key Features
* **Project Showcase:** A filtered gallery showing Ongoing, Completed, and Upcoming projects.
* **Service Pages:** Detailed sections for Civil Construction, Redevelopment, and Structural Consulting.
* **Responsive Design:** Fully optimized for mobile devices (essential for clients on the go).
* **Inquiry System:** A functional contact form for new project leads and vendor registration.
* **Location Integration:** Google Maps integration for site offices across Mumbai (Dadar, Bandra, Thane, etc.).

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript
* **Styling:** Custom CSS (with Flexbox/Grid)
* **Icons:** FontAwesome / Material Icons
* **Fonts:** Modern sans-serif typography for a corporate look
